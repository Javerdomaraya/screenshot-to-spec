# Historical implementation records

`implementation-steps/` contains the earlier Step 2, Step 3, and Step 4 source snapshots and notes. They are retained as background for the desktop database, IPC, and scheduling work.

These snapshots are historical documents, not active source files. Their paths, copied code, and verification instructions can predate the current folder structure and administrator authentication. Make changes in `src/`, `electron/`, `shared/`, or `tests/` instead of editing or copying a snapshot back into the app.

For current setup and commands, use the [project README](../../README.md). For the older manual IPC checks, read [scripts/README.md](../../scripts/README.md).
